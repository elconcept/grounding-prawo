# LexMachina CHAT — osobny plugin GPT/ChatGPT

Wydanie `1.0.0` jest przeznaczone do pracy w ChatGPT CHAT i stanowi osobny komponent marketplace. Nie zastępuje istniejącego `grounding-prawo` dla Claude/Codex ani nie wymusza jego serwera MCP.

Podstawa: osobisty Plugin Creator `akta-i-dowody`, wydanie `pluginrel_6afdb8ff27688191aa4ce96949c98dfa`, zaadaptowane etapy 1–8 oraz pierwotny rdzeń analiz akt/dowodów/chronologii. Część niezmienionych zasobów wspólnych jest współdzielona treściowo ze źródłem generatora `grounding-prawo`; detale w `SOURCE-RELEASE.json`.

Zasady: jeden oryginalny klasyfikator `prawny-router-v3` ([1]–[11]); fasada `prawo-polskie-v2`, `przewodnik-prawny-v2` jako gospodarz sesji, `shared` jako kanon. Brak obowiązkowego MCP, powłoki i Basic Memory. Weryfikacja prawa i wykonywanie skryptów tylko po rzeczywistym odczycie/wywołaniu; nigdy nie utożsamiaj istnienia dokumentu z automatyczną prawdziwością narracji. Brak E2E i braki źródeł oznaczaj jawnie.

To wydanie zawiera 12 skilli; nie jest pełną konsolidacją przyszłych bundle-pluginów ani wszystkich DR. Nie kopiować prywatnych akt spraw do publicznego repozytorium. Pozostałe bundle-pluginy będą integrowane osobno po adaptacji i walidacji.
