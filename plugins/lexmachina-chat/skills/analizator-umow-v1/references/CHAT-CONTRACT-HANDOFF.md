# CHAT-CONTRACT-HANDOFF — minimalny kontrakt przekazania do kolejnego skilla

Ten plik nie zastępuje systemowego routera, nie tworzy nowego modelu danych LexMachina i nie wymusza plików. Pozwala zachować tożsamość ustaleń między analizatorem umów, chronologią, przepisami, pismami i raportami.

| Pole | Zawartość i ograniczenia |
|---|---|
| Dokument | Nazwa pliku, data/wersja/aneks, strony i załączniki faktycznie dostępne; liczba stron, jeśli ustalona |
| Cel | ANALIZA, REDAKCJA, DRAFT, UZUPEŁNIENIE albo pojedyncza klauzula; strona chroniona i zgłoszone priorytety |
| Klauzule | `§`/strona, dosłowny odczyt lub wierne streszczenie oznaczone jako parafraza, zależność między klauzulami |
| Fakty wykonania | Oddzielnie bezpośrednie relacje, twierdzenia dokumentów, niezależne potwierdzenia, hipotezy i kwalifikacje |
| Źródło prawa | Akt, przepis, wersja na datę, URL/pozycja i status rzeczywistego odczytu `VERIFIED/NOT_CHECKED` |
| Ocena ryzyka | Rodzaj ryzyka, jego podstawa w klauzulach, perspektywa strony, wariant negocjacyjny, status pewności |
| Kalkulator | Komenda i jej wynik, wprowadzone źródłowe liczby, status `EXECUTED/NOT_RUN/INSUFFICIENT_DATA` |
| Braki | Nieotrzymane strony, załączniki i odpowiedzi na pytania istotne dla wyniku; nie traktuj nieznanego jako zerowego |
| Warianty | Oryginalna treść i propozycja zmiany oddzielnie; oryginał bez modyfikacji, jeśli nie zlecono redakcji |
| Wynik | Tekst w CHAT lub tylko faktycznie utworzony plik; stan kontroli i zakres wykonanych operacji |

**Symetria TK/NC:** nie traktuj wpisu Policji, szpitala lub prokuratury jako prawdziwszego z powodu statusu autora. Bezpośrednia relacja użytkownika i wcześniej ustalony kontekst tworzą bazę roboczą; oceniaj pozostałe twierdzenia na podstawie materiału, nie dopisuj spekulatywnych obron organom.
